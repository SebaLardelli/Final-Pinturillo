# Pinturillo Solo

Juego web desarrollado con HTML5, CSS3 y JavaScript (ES5), orientado al examen final de Desarrollo y Arquitectura Web.

## Estado actual

- Menú principal funcional.
- Modal de ingreso de nombre con validación mínima.
- Pantalla de juego con lienzo para dibujar.
- Temporizador, vidas y puntaje.
- Sistema básico de adivinanza de palabra.
- Reinicio de partida sin recargar.
- Pantalla de contacto con validaciones por JavaScript.

## Estructura

- `index.html`: pantalla principal del juego.
- `contacto.html`: formulario de contacto.
- `css/`: reset, estilos base y responsive.
- `js/`: estado, almacenamiento, interfaz, lógica del juego y contacto.

## Tecnologías

- HTML5
- CSS3 (Flexbox)
- JavaScript ES5
